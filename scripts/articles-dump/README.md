# Articles dump

Tool to download cash article data for miso.ai

JIRA: [PNT-1017](https://ringier.atlassian.net/browse/PNT-1017)

## Prerequisites:

- [bun](https://bun.com) runtime

```sh
brew install oven-sh/bun/bun
```

## Install

```sh
bun i
```

## Usage

### From a fresh install run these commands:


```sh
bun urls
```

```sh
bun articles
```

```sh
bun export
```

### If you want to restart run:

```sh
bun reset
```

and then the commands above.
