# Styleguide Default Factory

The styleguide default factory is used to render a filterable styleguide component list.

## 🔨 Usage

Styleguide Default factory call inside of the **APP**:

```tsx
import React from 'react';
import styleguideFactory from '../../../../../../../common/screens/Styleguide/components/Default/factory';
import {
  setLoading,
  setScreenReady,
} from '../../../../../../shared/actions/route';
import Breadcrumbs from '../../../../components/Breadcrumbs';
import StatusPage from '../../../StatusPage';
import Paragraphs from '../../components/Paragraphs';
import grid from '../../../../../../../common/assets/styles/grid.legacy.css';
import styles from './styles.legacy.css';

const breadcrumbItems = {
  count: 2,
  edges: [
    {
      node: {
        label: 'Styleguide',
        link: '/styleguide',
        __typename: 'ActiveMenuTrailItem',
      },
      __typename: 'ActiveMenuTrailItemEdge',
    },
    {
      node: {
        label: 'Paragraphs',
        link: null,
        __typename: 'ActiveMenuTrailItem',
      },
      __typename: 'ActiveMenuTrailItemEdge',
    },
  ],
  __typename: 'ActiveMenuTrailItemConnection',
};

const Styleguide = styleguideFactory({
  breadcrumbs: (
    <div className={grid.Container}>
      <Breadcrumbs pageUrl={'paragraphs'} items={breadcrumbItems} />
    </div>
  ),
  StatusPage,
  StyleguideComponents: Paragraphs,
  title: 'Paragraphs',
  styles,
  setLoading,
  setScreenReady,
});

export default Styleguide;
```

Make sure you always lazy load the styleguide components!

```html
<StyleguideParagraphsLazy path="styleguide/paragraphs" />
```

## 🤖 Generating the Styleguide components

For now this Default factory is used to render the automatically generated Styleguide/components/Paragraphs component.
This component can be automatically generated by the following command:

```properties
yarn styleguide --app beobachter
```

If you want to generate the styleguide paragraphs for all publications you can simply omit the app parameter:

```properties
yarn styleguide
```

### 😇 Important to know

Here are a few important pieces of information to get the most out of the autogenerated paragraphs.

What the styleguide script does is going through the Paragraph directory of the respective publication and checks whether or not a particular paragraph has an associated mockData file in the test directory (we need the mockData file to render the component which needs some props obviously).

❗ For this to actually work the mockdata file has to have the name "mockData.json" (which is the case anyway for 95% of our mockdata files)

In case a paragraph has no mockData file within the publication directory, it will also check the common directory (because often our paragraphs come from factories and the tests (respectively the mockData) live there).

Unless mockData has been found the paragraph will not be rendered in the Paragraphs component.

Another important thing is the structure of the mockdata within the file. The mockData has to be defined a such a way that it can be directly spreaded on a given component.

Basically the mockData need to be assignable to the initialProps (which are most likely used in a specific test file.) and are then spreaded onto the component:

```tsx
initialProps = JSON.parse(JSON.stringify(mockData));
const { container } = render(<Component {...initialProps} />);
```

You can checkout the TeaserStageParagraph factory tests or the BlockquoteParagraph factory tests to see this in action.

By structuring the content this way, it will also be usable for the autogenerated paragraphs, because the script will use the mockData in the same way - spreading them on the given paragraph.

You can also read the styleguide script to better understand how it operates:
`scripts/build-styleguide.js`
